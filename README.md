联盟 聊天转账生成器

品牌 联盟
作者 Lion
版本 2.0.0

本套源码为纯前端静态生成工具 包含微信对话 微信余额 微信红包 微信付款账单 微信收款账单 微信扫码 微信转账详情 微信安卓对话 支付宝聊天 支付宝转账 支付宝余额 QQ对话 淘宝订单 朋友圈截图 共十四类模板 全部页面离线运行 资源本地化 无任何外链依赖

运维入口 setup.sh 支持 build start stop reload restart monitor backup rollback log 八个指令 脚本位于 bin 目录 内置构建校验 端口探测 进程清理 备份打包 一键回滚 运行监控与访问日志

部署 上传至站点根目录 执行 bash setup.sh start 即可 默认端口 8080 可用 PORT 变量覆盖
